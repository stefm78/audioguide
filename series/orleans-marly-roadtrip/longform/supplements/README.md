# Compléments narratifs de durée

Ces fichiers ajoutent de la matière éditoriale aux sept chapitres principaux sans dupliquer leur structure de base.

- Ils sont insérés juste avant la conclusion du chapitre.
- Les sources propres au complément sont fusionnées avec les sources du chapitre.
- Ils doivent apporter une dimension nouvelle et documentée, jamais du remplissage.
- Le rendu final est contrôlé après synthèse : minimum 540 secondes par épisode principal.
- Le preset de voix n'est pas ralenti artificiellement pour atteindre la cible.

Les images restent externes et sont définies dans les chapitres principaux via Wikimedia Commons ; aucun média visuel n'est stocké ici.
